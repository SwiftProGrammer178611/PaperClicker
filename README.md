# Paper Clicker
## a simple modified cookie clicker controlled with the letter R. 

Link to try it out: https://paper-clicker.vercel.app/

# How to Play
Press R to start clicking
Hold R for 2 seconds to purchase the first upgrade in the list
Hold R for 4 seconds to purchase the next item Pliers in the List.
Hold R for 6 seconds to purchase the 3rd last double Paper clip item
The game automatically counts up, and faster based on the purchases of your upgrades

Thats it! I hope you have fun!
